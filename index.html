Machine Learning Classification And Loan Default Prediction

This project presents a loan‐default prediction model on LendingClub’s 2007–2010 data that, by rebalancing the training set and using a Random Forest, achieves an AUC of 0.67 and captures 22% of actual defaults.

Key Skills: EDA, feature engineering, data visualization, and machine learning classification with scikit-learn.
